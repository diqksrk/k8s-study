# 접속 가이드 (실습 0 이 막힐 때)

스터디를 시작할 때 1:1 로 받은 `k8s-study.zip` 으로 [HANDS_ON.md](../HANDS_ON.md) 의 '실습 0. 준비 · 접속' 을 합니다. 이 문서는 그 단계를 조금 더 자세히 적고, 자주 막히는 곳을 모았습니다. AWS 계정도 git 도 필요 없습니다.

`k8s-study.zip` 안에는 세 가지가 들어 있습니다.

- 실습 파일 (`labs` · `solutions` · `HANDS_ON.md` …)
- 내 접속 파일 `kubeconfig` — 내 칸(네임스페이스)에 들어가는 열쇠(토큰)가 들어 있습니다. 다른 사람에게 넘기지 마세요
- Windows 용 kubectl (`bin/kubectl.exe`) — Mac 은 쓰지 않고 brew 로 설치합니다

압축은 **다운로드 폴더**에 저장합니다. 명령은 누구나 같습니다. 이름이나 아이디를 바꿔 칠 곳은 없습니다.

## 1. 압축 풀고 kubectl · 접속 파일 설정 (한 번만)

**Windows** — PowerShell 에서 한 줄씩. 관리자 권한은 필요 없습니다.

```powershell
Expand-Archive "$HOME\Downloads\k8s-study.zip" -DestinationPath $HOME -Force

$p = [Environment]::GetEnvironmentVariable("Path", "User")
[Environment]::SetEnvironmentVariable("Path", "$p;$HOME\k8s-study\bin", "User")
[Environment]::SetEnvironmentVariable("KUBECONFIG", "$HOME\k8s-study\kubeconfig", "User")

$env:Path += ";$HOME\k8s-study\bin"
$env:KUBECONFIG = "$HOME\k8s-study\kubeconfig"

kubectl version --client
kubectl get pods
```

- 첫 줄은 홈 폴더에 `k8s-study` 폴더를 만듭니다. 탐색기의 '압축 풀기' 는 `k8s-study` 안에 `k8s-study` 를 한 겹 더 만들기 때문에 이 명령으로 풉니다. 다시 치면 고친 실습 파일까지 덮어쓰니 한 번만 칩니다.
- 가운데 세 줄은 kubectl 과 접속 파일을 **다음에 여는 창 · 탭부터** 쓰게 합니다(내 계정에만 적용).
- `$env:` 두 줄은 **지금 창에도** 바로 적용합니다.

**Mac** — 터미널에서 첫 줄부터 한 줄씩.

```bash
setopt interactivecomments; echo 'setopt interactivecomments' >> ~/.zshrc
unzip -q ~/Downloads/k8s-study.zip -d ~
echo 'export KUBECONFIG=~/k8s-study/kubeconfig' >> ~/.zshrc; export KUBECONFIG=~/k8s-study/kubeconfig
brew install kubectl
kubectl version --client
```

- 첫 줄은 명령 줄 끝의 `# 설명` 까지 붙여 넣어도 에러가 나지 않게 하는 설정입니다(Mac 기본 터미널은 `#` 뒤를 설명으로 보지 않습니다).
- 셋째 줄은 접속 파일을 지금 창과 앞으로 여는 창 · 탭 모두에서 쓰게 합니다.

`Client Version: …` 이 나오면 성공입니다. 버전 숫자는 사람마다 달라도 됩니다.

## 2. 확인하기

```powershell
cd ~/k8s-study
kubectl get pods
kubectl auth can-i create deployments
```

이렇게 나오면 성공입니다. 칸 이름(`k8s-study-…`)은 사람마다 다릅니다.

```text
No resources found in k8s-study-… namespace.
yes
```

## 자주 막히는 곳

- `Expand-Archive` · `unzip` 이 파일을 못 찾음 — 압축이 다운로드 폴더가 아닌 곳에 있거나, 이름이 `k8s-study (1).zip` 처럼 바뀌었습니다. 다운로드 폴더에 `k8s-study.zip` 으로 둡니다. Mac 에서 이미 풀린 `k8s-study` 폴더가 다운로드에 있으면 `mv ~/Downloads/k8s-study ~`.
- Mac `unzip` 이 `already exists` 를 물음 — 이미 푼 것입니다. `N` 을 누르고 다음 줄로 넘어갑니다.
- `kubectl : 'kubectl' 용어가 ... 인식되지 않습니다` — Windows `$env:` 두 줄(지금 창에도)을 빠뜨렸거나, 보안 프로그램이 `kubectl.exe` 를 지웠습니다. `Test-Path "$HOME\k8s-study\bin\kubectl.exe"` 가 `False` 면 조교에게.
- 맨 앞이 `PS C:\Windows\system32>` — 관리자로 연 창입니다. 관리자 권한은 필요 없습니다. 보통 PowerShell 을 열고 첫 줄부터 칩니다.
- 탐색기로 먼저 풀었음 — `k8s-study` 안에 `k8s-study` 가 한 겹 더 생깁니다. 그 폴더는 두고 첫 줄 명령부터 칩니다.
- 새 탭에서만 안 됨 — Windows Terminal 이 바뀐 설정을 다시 읽지 않은 경우입니다. Windows Terminal 을 닫았다 다시 엽니다.
- Mac 에서 `command not found: #` · 이상한 인자 에러 — 첫 줄(`setopt …`)을 치기 전에 `# 설명` 이 붙은 줄을 붙여 넣었습니다. 첫 줄부터 다시 칩니다.
- `Unable to connect to the server` — 회사망에서 클러스터로 가는 길이 막힌 경우입니다. VPN 을 켜고 끄며 다시 해 보고, 그래도 안 되면 조교에게.
- `No resources found in default namespace.` — 받은 접속 파일이 아니라 다른 설정이 쓰이고 있습니다. 1번의 KUBECONFIG 줄을 다시 칩니다.
- 다른 사람 네임스페이스에서 `Forbidden` — 정상입니다. 내 칸 안에서만 만들고 지울 수 있고, 노드(서버)는 보기만 할 수 있습니다.
- `error: You must be logged in to the server (Unauthorized)` — 접속 파일이 바뀌었거나 클러스터가 새로 만들어진 경우입니다. 새 압축을 받으세요.

## 스터디가 모두 끝나면

접속 설정을 지웁니다. 원래 쓰던 쿠버네티스 설정으로 돌아갑니다.

- Windows — `[Environment]::SetEnvironmentVariable("KUBECONFIG", $null, "User")` 를 치고 터미널을 새로 엽니다.
- Mac — `~/.zshrc` 의 `export KUBECONFIG=~/k8s-study/kubeconfig` 줄을 지웁니다.
